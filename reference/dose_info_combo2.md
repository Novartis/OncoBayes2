# Dataset: trial dose information for a dual-agent combination study

The data set defines all pre-defined dose-levels which can be explored
in the dual-agent example trial.

## Usage

``` r
dose_info_combo2
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 42
rows and 4 columns.

## Details

- group_id:

  study

- drug_A:

  drug A dose amount

- drug_B:

  drug B dose amount

- dose_id:

  unique id of record
